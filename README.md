# awwwards-craft

Agent Skill for building Awwwards-level websites with Astro, TypeScript, pure CSS, GSAP and Lenis.

## Install

```bash
npx skills add fiqryq/awwwards-craft
```

Works with Claude Code, Codex, Cursor, Copilot, Gemini CLI, OpenCode and more.

**Claude Code plugin**

```
/plugin marketplace add fiqryq/awwwards-craft
/plugin install awwwards-craft@awwwards-craft
```
